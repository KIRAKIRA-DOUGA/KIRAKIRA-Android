# 功能现状

[返回项目首页](../README.md) · [实现说明](implementation.md) · [开发指南](development.md)

本文记录当前原型的可见行为和限制。所有视频、用户、评论与弹幕均为本地演示数据，未接入真实播放器、网络业务或登录会话。

## 主界面与设置入口

底部导航包含 **首页（Home）、搜索（Search）、关注（Following）、我（Me）**：

- 首页展示 KIRAKIRA 标题、头像占位及演示视频卡片；头像跳转“我”，视频卡片进入独立视频页。
- 搜索页展示静态 SearchBar，关注页展示标题。
- “我”使用占位资料和官方 `SegmentedListItem` 分组菜单，包含个人资料、统计、个人主页、历史、收藏和设置入口，尚未接入真实账号数据。
- 设置页分为“我”“常规”与账户操作，外观、关于和切换账户入口可用；其他设置项和登出尚未接入业务。

四个 Tab 按排列顺序左右切换，顶栏与页面内容一起移动，底部导航栏固定。支持跨 Tab 直接切换，连续点击转向最新目标，重复点击当前 Tab 不重播。底栏选中图标分别呈现描边／填充形变、轻摆或向外扩散的动效。

选中 Tab、首页与“我”的滚动位置可恢复；首次显示和状态恢复不播放切换动画。从设置或视频页返回时恢复原 Tab 和滚动位置。在主界面按系统返回退出应用，不额外跳转首页。

设置、外观、关于和切换账户页共用可折叠大标题栏：首次进入默认折叠，内容到顶后下拉展开，上滑收起，并保存展开程度。

界面支持中文和英语，默认跟随系统语言；Android 13+ 可通过系统应用语言设置切换。Demo 用户名、签名、评论、弹幕、视频标题、简介及演示元数据集中维护在 [demo_strings.xml](../app/src/main/res/values/demo_strings.xml)，不随界面语言切换；资源维护规则见[贡献指南](../CONTRIBUTING.md#compose-与界面规范)。

## 视频页

### 布局与简介

播放页状态栏固定为黑色背景和浅色图标，退出后恢复应用主题的系统栏样式。顶部固定 16:9 视频占位及“简介／评论／弹幕”标签栏，下方支持左右滑动与点击标签平滑切换，选中标签同步当前页。三个页面首尾不循环，各页独立纵向滚动并保留位置；宽屏内容居中，视频高度不超过可用高度的 40%。

简介包含作者、关注、标题、视频信息、介绍与操作栏。关注、赞踩和收藏可切换演示状态，赞踩互斥；下载、分享和更多显示待接入提示。当前不包含播放器或真实业务操作。

标签、滚动位置和交互状态支持旋转及系统状态恢复，退出视频页后重新进入恢复默认值。

### 评论

提供 120 条演示评论，每 20 条对应一页，使用连续滚动列表：

- 页码与排序工具栏固定在评论区右上角；页码根据工具栏下方最上面的可见评论更新，可跳转到当前排序下的指定页或固定楼层，目标避开工具栏。
- 支持按时间、评分正序或倒序排列，默认时间倒序；切换排序回到第一页。
- 赞踩互斥，评分排序随演示投票更新；回复与更多显示待接入提示。
- 列表首项显示总评论数，随内容滚动且不计入页码。空间足够时与工具栏同一行对齐，窄屏或大字体下改为上下排列。

### 弹幕

弹幕列表左侧显示时间，右侧正文支持长按选择部分文字和复制。首项显示总条数并随内容滚动，数量统一取自占位数据列表。

评论和弹幕的分段样式、间距与工具栏布局见[视频列表布局](implementation.md#视频列表布局)。

## 外观

### 明暗模式与配色

“设置 → 外观”支持独立选择明暗模式与主题配色。默认以产品主色 `#F06E8E` 为种子生成完整浅深色方案，可选择 Android 12+ 系统动态颜色，或六种预设及自定义颜色；低版本 Android 使用手动配色。

自定义颜色选择器提供色盘、亮度与六位 HEX 输入。预设色板以三色分区显示，选中时通过 Expressive 动画从圆形变为圆角矩形。选择立即生效并持久保存；自定义草稿仅在确认后保存，取消不改变主题。

系统配色与手动配色之间切换会保留手动选色。自定义颜色独立保存，选择预设不会覆盖，再次打开选色器时恢复上次确认的自定义颜色。

手动配色提供柔和色调（默认）、单色、中性、鲜艳、表现力、忠实、内容、彩虹、缤纷与经典强调色十种算法。色板与选色器预览同步更新，算法选择持久保存。黑白灰主题可选择“单色”；系统动态配色沿用系统算法。所有方案沿用 `MaterialExpressiveTheme` 的形状、排版和动效。

“经典强调色”使用白色／深灰色顶栏和底栏、分层灰阶背景，并在浅深模式下保留所选原色。为保留原色，极浅或极深选色可能对比不足，不保证所有文字达到 4.5:1；颜色角色及对比度规则见[贡献指南](../CONTRIBUTING.md#主题配色约束)。

### 阴影

阴影开关默认关闭，切换立即生效并持久保存。开启后所有应用顶栏始终显示阴影，底部导航栏也显示阴影；大标题展开或折叠不改变阴影高度。搜索页没有顶栏，仅底栏生效。

浅深色、系统动态配色和所有手动配色共用此设置，保留 Material 3 Expressive 组件、配色与色调高度策略。具体高度见[主题实现](implementation.md#主题实现)。

## 账户与认证

### 切换账户

“设置 → 切换账户”提供交互原型：游客固定置顶，两个演示账户使用 RadioButton 表示单选状态。普通账户可向左滑动露出圆角移除按钮，完整滑动同样进入移除确认；游客不可滑动。保留编辑模式和无障碍移除操作，移除当前账户会切回游客。

选择及移除结果在页面往返、旋转和系统状态恢复时保留；全新启动恢复演示数据，不保存真实登录会话，也不改变“我”的占位资料。

### 添加账户

添加账户进入独立的邮箱密码认证页，包含品牌星星、大标题、描边输入框、密码显隐、注册入口与 Expressive 主按钮。支持邮箱格式校验、键盘下一步／提交以及错误提示。

登录与注册当前显示待接入提示，不发起请求、不模拟成功、不修改演示账户。提交中与失败重试状态当前只在 Preview 展示：提交中保持按钮尺寸，仅显示居中的 `LoadingIndicator`，禁用重复提交，并向无障碍服务说明正在登录。

表单兼容浅深色、动态配色、大字体和横屏；键盘出现时内容可滚动，底部系统内边距随内容滚动。邮箱支持进程重建恢复，密码仅在内存中保留、进程重建后为空，界面重建后默认隐藏；数据流见[认证状态](implementation.md#认证状态)。

## 关于与开源组件

“我 → 设置 → 关于 → 开源组件”使用 AboutLibraries 自带的 Material 3 列表和组件详情 Sheet，继承应用主题，支持离线阅读及返回栈、列表位置恢复。此页保留第三方列表样式，外层导航与顶栏沿用项目组件。

许可证数据按 Debug / Release 构建自动生成，并补充 Material Symbols 与 AOSP 转场移植声明。生成、维护与检查方法统一见[开源声明说明](../third_party/aboutlibraries/README.md)。

## 启动屏

启动屏始终跟随系统浅深色模式：浅色为品牌粉色背景和白色图标，深色为深灰背景和品牌粉色图标，不随应用内外观设置、动态颜色或自定义主题色变化。应用页面仍使用保存的外观设置。启动图标使用独立资源，桌面与关于页图标保持原样。

全新启动时，页面准备好后播放图标先收缩、再展开揭示页面的遮罩退出动画，页面自身不缩放。后台返回、旋转、页面恢复和应用内主题切换均不重播；关闭系统动画时直接显示页面。

离开前台、销毁或窗口尺寸变化时清理过渡。过渡期间屏蔽底层页面触摸与无障碍焦点，不拦截系统返回。配色、时序与清理机制见[启动动画](implementation.md#启动动画)。
