# 功能现状

[返回项目首页](../README.md) · [实现说明](implementation.md) · [开发指南](development.md)

本文记录当前客户端的可见行为和限制。认证、本机账号管理、首页视频、作者资料、评论与弹幕均接入真实 API。

## 主界面与设置入口

底部导航包含 **首页（Home）、搜索（Search）、关注（Following）、我（Me）**：

- 首页展示 KIRAKIRA 标题、账号头像及真实视频卡片；头像跳转“我”，视频卡片进入独立视频页。
- 搜索页展示静态 SearchBar，下方与关注页正文统一展示“暂未开放”占位。
- “我”的账号入口使用紧凑横向布局，保留 72dp 头像：游客显示“登录”，已登录显示昵称和等宽字体的 `@用户名`，右侧统一显示箭头。整行点击进入登录或自己的主页；主页展示真实昵称、用户名、头像和签名，顶部 banner 暂用本地樱花占位背景，关注统计及作品按接口加载，失败显示重试或错误提示。账号入口与分组菜单使用官方 `SegmentedListItem`；历史、收藏等尚未接入真实业务。
- 设置页分为“我”“常规”与账户操作，屏蔽和隐藏、邀请码、播放、弹幕、外观、关于和切换账户入口可用；登出可移除当前本机会话；其他设置项尚未接入业务。

自己与作者的用户主页在正文昵称完全滚出可见区域后，在 TopBar 显示单行昵称，超长省略；向下滚动使正文昵称重新可见时，顶栏昵称隐藏。

四个 Tab 按排列顺序左右切换，顶栏与页面内容一起移动，底部导航栏固定。支持跨 Tab 直接切换，连续点击转向最新目标，重复点击当前 Tab 不重播。底栏选中图标分别呈现描边／填充形变、轻摆或向外扩散的动效。

选中 Tab、首页与“我”的滚动位置可恢复；首次显示和状态恢复不播放切换动画。从设置或视频页返回时恢复原 Tab 和滚动位置。在主界面按系统返回退出应用，不额外跳转首页。

设置、屏蔽规则管理、邀请码、播放、弹幕、外观、关于和切换账户页共用可折叠大标题栏：首次进入默认折叠，内容到顶后下拉展开，上滑收起，并保存展开程度。

界面支持中文和英语，默认跟随系统语言；Android 13+ 可通过系统应用语言设置切换。服务器返回的用户资料、评论、弹幕、视频标题与简介保留原文；设计预览使用空表单、游客账号与空列表，不再内置演示账号或邀请码；资源维护规则见[贡献指南](../CONTRIBUTING.md#compose-与界面规范)。

## 内容状态

首页、资料与关注统计、作者作品、视频详情、评论、弹幕、开源组件及媒体查看器的加载失败与空内容统一使用 `ContentUnavailableView`。失败保留具体错误和统一重试按钮；已有内容刷新失败时保留内容并展示内嵌错误。首页、弹幕和作者作品已加载的空状态在刷新期间保持显示，由下拉刷新指示器反馈进度，避免空状态消失后再次出现。收藏、搜索和关注的未开放占位使用相同组件，不提供无效重试。

图片加载失败和视频播放失败在黑底上展示统一错误与重试操作，返回、关闭和全屏入口仍可用；播放器重试重新准备媒体。加载中仍使用 `LoadingIndicator`。表单校验、登录与会话错误，以及发布、保存等操作反馈保留原有呈现方式。

## 视频页

### 播放与简介

首页读取 Rosales `/video/home`，支持刷新、加载、空结果和失败重试；服务端目前最多返回 100 条，没有客户端分页接口。每张卡片通过真实 KVID 进入详情。首页封面、作者名、播放量、时长及发布时间均来自服务器，缺失字段使用中性占位，不生成虚构统计。

首页与作者主页共用视频卡片，网格和列表布局均为标题预留两行，超出省略；首页卡片的上传者仅显示单行昵称，作者主页卡片不显示上传者行，也不保留该行空白。播放量与时长以图标加内容并排显示在同一行，发布时间以图标加内容单独占一行；各字段超长省略，不自动换行，使同一布局、宽度与字体设置下的卡片等高。播放量只显示数字，时长只显示时间值，缺失值显示「—」；无障碍标签保留各字段含义。视频详情页播放量同样显示播放图标与数字。

视频默认显示封面，点击播放后创建 Media3 播放器；开启「设置 → 播放 → 自动播放」后，新进入的视频页面在前台取得可播放内容后自动开始一次。支持 HTTPS DASH、HLS 和渐进式媒体、播放／暂停、进度拖动、分 P 选择、全屏、播放失败重试。多个分 P 时，仅在「简介」页提供按服务端顺序展示的切换入口，手动切换后从头播放；暂停时切换仍保持暂停。普通布局播放器高度不超过可用高度的 42%，全屏占满当前窗口并请求横屏，支持两个横屏方向；退出恢复此前方向策略，系统返回先退出全屏。系统限制方向的多窗口或大屏环境仍按实际窗口展示。播放中离开视频页可按设置转为应用内小窗；认证入口先暂停播放。未保留小窗时释放播放器，返回后需手动播放；页面恢复保留分 P 和位置，不自动播放。没有后台音频服务、离线下载或自动连播。

「设置 → 播放」提供独立的「应用内小窗播放」「应用外小窗播放」（均默认开启）和「自动播放」（默认关闭），设置全局持久保存。应用内开关控制播放中或缓冲待播放时离开视频页后的自动小窗，应用外开关控制正在播放时离开应用后的系统画中画。播放器控制栏不提供手动画中画入口，暂停时弹幕开关继续显示。自动播放不因刷新、旋转、后台返回或进程恢复重复触发，也不自动连播下一分 P。

播放器采用黑色渐变遮罩，画面中央显示带半透明黑色圆形背景的 Filled 播放／暂停图标，底部显示时间、弹幕开关、全屏操作与圆头进度条、圆形手柄，不使用大块不透明控制栏背景。进度条使用官方圆形尺寸手柄及其交互反馈，主题色为已播放进度、浅灰为已缓冲进度、暗灰为未缓冲部分；缓冲位置随播放器更新，切换分 P 或释放播放器时清空。播放期间无操作 3 秒后控制栏和返回按钮一起隐藏；轻触画面显隐，操作重置计时。暂停、结束、错误、拖动及 TalkBack 触摸探索期间保持显示，缓冲时在播放／暂停按钮的同一半透明黑色圆圈内显示白色 LoadingIndicator，尺寸和位置保持一致。

播放器右上角提供画质与倍速胶囊按钮，点击打开 M3 Expressive 底部面板，打开期间不暂停播放且控制栏保持显示；关闭后重新计时，进入画中画、切换全屏或离开视频页时关闭。画质从实际支持的视频轨道生成，提供自动与按清晰度降序的手动选项，每项右侧显示对应视频轨道的 Kbps 码率（四舍五入为整数，未知时省略）；尚未加载轨道时入口禁用。全局保存自动／手动模式与首选清晰度，其他视频或分 P 缺少首选清晰度时临时回退自动，不覆盖偏好；切换保留播放位置与暂停状态。

倍速提供 0.25×、0.5×、0.75×、1×、1.25×、1.5×、1.75×、2×、3×、4× 快捷项，以及 0.25×–4× 对数滑杆。默认吸附预设，开启「连续调速」后按两位小数调整；「保持音调」默认开启。倍速和两个开关在当前视频内、分 P 切换及页面恢复时保留，退出后进入新视频恢复 1×、关闭连续调速、开启保持音调。面板内调整立即生效，画质选中即关闭，倍速面板保持打开。

应用内小窗默认右下角，宽 192dp、16:9、8dp 圆角，窄窗口按可用空间缩小；可拖动并吸附左右边缘，避让系统栏、键盘与主界面底部导航。小窗提供播放／暂停、关闭，点击画面返回对应视频页，保留分 P、进度、画质、倍速与暂停状态。小窗不显示弹幕、进度条或画质／倍速面板。暂停、结束或错误状态离开视频页不创建小窗，已创建的小窗暂停后保留；关闭小窗或关闭应用内开关停止播放。打开另一视频、账号切换、登出或小窗播放失败时清理旧会话。

正在播放且「应用外小窗播放」开启时，视频页或应用内小窗回到桌面、切换其他应用会自动进入系统画中画。系统画中画仅显示视频，MediaSession 提供播放／暂停控制；Android 12+ 使用自动进入，Android 8–11 在离开应用时进入。不支持、未允许或未进入系统画中画时，后台释放播放器。关闭系统画中画停止播放，展开回应用恢复此前视频页或小窗状态。配置变化保留播放会话，进程重建不自动恢复播放或小窗。

简介展示真实作者、关注关系、标题、播放量、日期、分区、描述和赞踩。分区名称随应用语言显示中文或英语，七个已知分区的文案与 Cerasus 多语言资源一致；未知分区保留接口原值，空分区不显示。游客点击互动进入登录，登录完成后由用户再次操作，不自动重放写请求。赞踩、取消和关注操作通过服务器确认并刷新状态；操作期间防止重复提交。收藏、下载、分享、回复及更多入口提示暂不可用，不改变虚构状态或计数。

### 作者与头像

作者入口按 UID 加载真实用户资料、关注统计和作品；顶部 banner 暂用与 Web、Apple 客户端相同的本地樱花占位背景。“我”的主页使用同一布局，并以本地账号资料作为加载时的回退。关注／粉丝列表、资料编辑及收藏内容仍未开放。 资料信息与背景随纵向滚动移出，仅作品／收藏 Tab 栏在到达顶部导航栏下方后吸顶；左右滑动仍可切换 Tab。

头像支持 Cloudflare 图片 ID 以及公开 HTTPS URL；服务端封面字段保留，当前 Profile 页暂不展示远程封面。头像可展开到全屏查看器，保留原有共享转场、缩放、控件自动隐藏、保存和复制能力；查看和导出使用不限制宽度的图片分发地址，网络请求不携带会话。图片缺失或加载失败时保留默认头像，非法图片 ID 不生成网络请求。

### 评论与弹幕

评论按服务端楼层升序、每页 20 条双向连续加载：接近列表上下边缘时自动补齐相邻页，向前插入保留当前阅读位置。右上角悬浮 Toolbar 的上一页、下一页和页码输入仅用于快速跳转，页码随顶部可见评论更新；已加载页直接定位，未加载页请求成功后以目标页重新建立连续列表，失败保留原内容与位置。不提供后端没有实现的全局评分排序和楼层定位。列表显示真实作者头像、昵称、正文、时间、楼层和赞踩。空评论返回缺失总数字段时按空列表处理。支持一级纯文本评论发布（非空，少于 20,000 字符），成功显示服务器回传内容并读取、定位末页；不渲染评论中的 HTML。首页、视频详情、评论、弹幕和作者资料使用 Compose Material 3 Pull To Refresh；评论只有回到第 1 页最顶部才能下拉刷新，刷新期间不在列表顶部插入加载指示器，避免内容跳动；刷新成功后重建第 1 页列表，空列表也可刷新。中间页顶部只加载前页，不触发刷新；上下加载失败分别提供重试，已有评论继续保留。

弹幕按播放秒数排序，显示真实内容并支持下拉刷新和发布。发送时记录当前分 P 的播放秒数，默认采用白色、中号、从右向左、非彩虹样式；发送栏的样式入口打开 Material 3 Expressive 底部面板，支持九种预设色、HSV／亮度／六位 HEX 自定义颜色、小中大字号、从右向左／顶部／底部／从左向右模式及彩虹样式，并提供实时预览。普通选择立即生效，关闭面板保留选择，自定义颜色确认后应用；重置恢复默认。样式在当前视频内连续发送、切换 Tab 和旋转时保留，退出视频、进程重建或切换账号恢复默认，不持久化。输入上限为 2,000 字符。Rosales 弹幕未区分分 P，各分 P 共用弹幕池，按当前分 P 的播放时间显示；切换分 P 从对应进度重新计算。弹幕读取采用公共接口，不宣称应用了账号的个性化过滤。

视频页就绪后自动读取弹幕，无需打开弹幕 Tab。视频画面支持四种模式、原始颜色、三档字号与粉蓝彩虹描边；播放器基准字号为 12／16／22sp，独立于发送预览，叠加全局字号缩放。弹幕按各自实测高度紧凑排布，垂直间隔为 2dp，不按最大字号统一预留行高。暂停及缓冲时冻结，跳转和全屏尺寸变化后按当前进度恢复；系统画中画隐藏弹幕，退出后恢复。弹幕覆盖实际视频区域，不进入黑边、不拦截播放器操作。滚动弹幕默认基准速度为 144dp/s，穿屏时长为实际视频宽度（dp）÷（144 × 用户滚动倍率）；例如 360dp 宽默认为 2.5 秒。固定弹幕显示 4 秒，两者均随视频倍速变化；轨道不足时跳过当条，不延迟堆积。发送成功刷新弹幕池，不额外插入本地副本。读取失败不阻断视频，可在弹幕 Tab 手动重试。

“设置 → 弹幕”提供显示开关、不透明度（10%–100%，步长 5%）、字号缩放（50%–200%，步长 5%）、显示区域（25%／50%／75%／100%）、滚动速度（0.5×–2×，步长 0.1×）及四种模式独立开关。默认开启、100% 不透明度、100% 字号、100% 区域、1× 滚动速度，四种模式均显示。显示区域取实际视频区域顶部所选比例，底部固定弹幕排在该区域下边缘；滚动速度只改变滚动弹幕的穿屏时长。播放器快捷开关使用 M3 Expressive Switch，滑块分别显示 Cerasus 的弹幕／关闭弹幕图标；开关与设置同步，全部偏好即时生效、本机跨视频与账号共享、重启后保留，随非敏感设置参与系统备份。没有密度设置；显示偏好不改变发送样式。

评论和弹幕在各自 Tab 底部提供常驻 M3 Expressive 悬浮输入区：草稿为空时为单行药丸，输入框、颜文字、弹幕样式（仅弹幕）和发送按钮同排；开始输入后展开为圆角两行布局，上方编辑文字，下方排列操作按钮。清空或发送成功后恢复单行药丸。支持直接输入和最多五行自动增高，继续输入时在框内滚动；颜文字面板展开时输入框最多显示两行，为选取内容留出空间。发送框随键盘上移，列表末项可滚动至其上方。

颜文字入口沿用 Cerasus 的圆润图标，点击后收起键盘，在输入区下方展开分类面板。提供开心、问候、卖萌、忧伤、无语五类共 268 项；点击条目在光标处插入或替换选中文字，可连续选择，不自动发送。超出原有输入上限时整项拒绝并提示。键盘按钮恢复编辑，返回先关闭面板；切换 Tab、打开弹幕样式、进入全屏或画中画时关闭面板并保留草稿，账号切换清除草稿和编辑状态。最近使用初始为空，仅在成功插入时记录，去重保存最新 24 项，评论、弹幕和本机账号共用；重启后保留，不进行云同步或系统备份。发送成功清空正文，发送失败保留草稿。

评论和弹幕请求分别加载，失败不阻断视频。发布失败保留流程内存中的草稿；网络中断时提示先刷新确认，客户端不自动重发。账号切换会取消旧请求并清除旧账号的互动状态和草稿。分段条目布局见[视频列表布局](implementation.md#视频列表布局)。

## 屏蔽和隐藏、邀请码

「设置 → 屏蔽和隐藏」采用分类总览与独立管理页，支持屏蔽用户、隐藏用户、标签、关键词和正则表达式。总览按用户管理、内容规则分组显示数量。管理页按每页 20 条加载，支持下拉刷新、加载更多、添加和解除；用户通过 UID 查询资料后确认，标签通过搜索已有标签选择添加。关键词与正则去除首尾空白后限制为 1–30 字符，正则语法与安全校验由服务端完成。缺失关联资料时保留规则标识；缺失 UID 的用户规则无法调用当前后端的按 UID 解除接口，因此不提供可点击的解除操作。

「设置 → 邀请码」展示未使用、已使用和总数，支持生成、状态筛选及复制。列表未使用优先，同组按生成时间倒序；生成成功立即显示新码，随后列表刷新失败不会丢失该结果。生成冷却由服务端决定，未提供剩余时间，因此不显示推测倒计时。不提供分享、删除或兑换。

两处设置均保存到当前账号的服务端数据；游客可进入登录并在完成后返回原页。切换账号或退出会清除旧列表、输入与弹窗，并取消旧请求。已有内容及空状态刷新时保持显示；失败保留内容并提供重试，写请求不自动重放。页面使用主题色统计卡、Material 3 Expressive 分段列表和底部添加面板，中英文同步。

内容过滤统一由后端执行，App 不维护本地过滤引擎；规则保存成功不代表现有每个内容接口都已支持所有规则。当前弹幕读取仍为公共请求，未接入个性化过滤，本次未改变内容接口请求方式。

## 外观

设置页中仅「显示弹幕」总开关随开启状态改变整行背景颜色和形状。「阴影」「应用内小窗播放」「应用外小窗播放」「自动播放」及四种弹幕模式开关仅通过 Switch 表达开启状态，保留整行点击、官方按压反馈与分组样式。

### 明暗模式与配色

“设置 → 外观”支持独立选择明暗模式与主题配色。默认以产品主色 `#F06E8E` 为种子生成完整浅深色方案，可选择 Android 12+ 系统动态颜色，或六种预设及自定义颜色；低版本 Android 使用手动配色。

自定义颜色选择器提供色盘、亮度与六位 HEX 输入。预设色板以三色分区显示，选中时通过 Expressive 动画从圆形变为圆角矩形。选择立即生效并持久保存；自定义草稿仅在确认后保存，取消不改变主题。

系统配色与手动配色之间切换会保留手动选色。自定义颜色独立保存，选择预设不会覆盖，再次打开选色器时恢复上次确认的自定义颜色。

手动配色提供柔和色调（默认）、单色、中性、鲜艳、表现力、忠实、内容、彩虹、缤纷与经典强调色十种算法。色板与选色器预览同步更新，算法选择持久保存。黑白灰主题可选择“单色”；系统动态配色沿用系统算法。所有方案沿用 `MaterialExpressiveTheme` 的形状、排版和动效。

“经典强调色”使用白色／深灰色顶栏和底栏、分层灰阶背景，并在浅深模式下保留所选原色。为保留原色，极浅或极深选色可能对比不足，不保证所有文字达到 4.5:1；颜色角色及对比度规则见[贡献指南](../CONTRIBUTING.md#主题配色约束)。

### 阴影

阴影开关默认关闭，切换立即生效并持久保存。开启后所有应用顶栏始终显示阴影，底部导航栏也显示阴影；大标题展开或折叠不改变阴影高度。搜索页没有顶栏，仅底栏生效。

浅深色、系统动态配色和所有手动配色共用此设置，保留 Material 3 Expressive 组件、配色与色调高度策略。具体高度见[主题实现](implementation.md#主题实现)。

## 账户与认证

### 切换账户

“设置 → 切换账户”固定置顶游客，其后为本机真实登录过的账号。登录／注册成功会以 UUID 去重并选中该账号；“我”及自己的资料页同步更新，退出应用后仍保留。不会预置演示账号。

点击其他账号会先向服务器校验并更新资料，校验及本地保存成功后才切换；请求中目标账号行固定区域显示 Expressive `LoadingIndicator` 和“正在切换”，不在列表顶部插入加载器。等待时可滚动和返回，重复切换／移除禁用，失败提示标明目标账号并保留重试与重新登录入口。游客切换可离线完成且保留其他会话。切换失败不替换当前其他账号；网络或超时保留会话，校验拒绝提示重试／重新登录。明确失效的 token 被清除，账号条目保留以便重新登录。

普通账号保留左滑移除、编辑模式和无障碍移除入口，均需确认；游客不可移除。移除当前账号／设置中的登出会清除该本机会话并回到游客，其他账号不变。后端登出仅清浏览器 Cookie，因此此操作不声明撤销服务器 token。存储故障可重试，必要时在明确确认后清除本机账号数据；服务器账号不受影响。

### 添加账户

添加账号或游客点击“我”的登录入口进入认证页。所有步骤（包括登录首页）在固定的 Material 3 Expressive CenterAlignedTopAppBar 中显示主题色图标：KIRAKIRA Logo 40dp，其余官方 Material Symbols Rounded 32dp；正文保留左对齐大标题、说明、表单和形状可变的主按钮。注册有四段进度提示，参考 Apple 端的步骤组织，保留 Android Material 3 Expressive 与 Navigation 3：

- 邮箱密码登录先检查 2FA：未开启时直接登录；邮箱验证进入六位验证码步骤并发送验证码；TOTP 接受身份验证器、备用码及恢复码。使用恢复码移除 TOTP 的行为由后端决定，界面提前说明。
- 注册按“资料 → 邮箱与密码 → 邀请码 → 邮箱验证”进行；确认密码紧跟密码，可选密码提示在后，最后一页只输入验证码。用户名和邮箱分别在前两步查重，邀请码页校验后发码。注册成功获得会话并返回进入认证的来源页面。
- 忘记密码先检查验证器类型。无 TOTP 的账号通过邮箱验证码设置新密码，完成后回到登录；启用 TOTP 的账号按 Cerasus 当前能力提供说明与管理员问题页面入口，不伪造找回接口。
- 验证码提供发送与重新发送，按邮箱显示 60 秒冷却，处理服务端冷却及每日次数上限。关闭后重开页面在当前进程中仍保留冷却；进程重启后的限制由服务器继续执行。

认证的各步骤使用独立 Navigation 3 页面，保留各自滚动位置并复用应用转场与预测性返回。顶部返回箭头和系统返回逐级回到上一步；登录入口的系统返回及各页关闭按钮退出整个认证流程。返回时取消当前请求，避免请求结束后重新进入刚离开的步骤。同一流程逐步返回保留非验证码草稿，修改密码会重新校验确认密码。前进后等待页面 RESUMED 且输入框可用，再聚焦首个待填写字段；返回不强制弹键盘。邮箱、用户名、确认密码、邀请码和格式不正确的验证码错误显示在对应字段附近并聚焦；网络及不能可靠归属字段的认证失败仍显示页面级提示。

所有异步操作展示 `LoadingIndicator`、禁用重复提交，并显示中英文失败与重试提示。关闭认证页后，条目 ViewModel 的任务随出栈取消；不会把请求失败显示为已登录。服务端已认证但本地保存失败时保留当前页内存中的待保存会话，重试只保存会话，避免重复注册／验证码提交。注册请求网络中断时仍可能已在服务器完成，可返回登录，不自动重放请求。

本地会话保存重试无需再次请求网络。资料响应身份不一致或格式异常时不会保存账号；登录成功等待页面关闭期间，表单与流程切换入口禁用。

邮箱通过 SavedState 恢复；密码、摘要、确认密码和验证码不落盘，进程重建回到登录页，密码为空。界面重建或步骤切换后默认隐藏密码。键盘展开和短窗口只通过正文滚动容纳内容，不改变图标、文字或间距大小；表单最大宽度 480dp，底部系统内边距随滚动内容保留。账号资料刷新失败时可使用刚获得会话的邮箱和 UID 显示基本信息，后续切换／启动会再刷新；不会填充假昵称或统计。实现与安全边界见[API 与会话](implementation.md#api-与会话)。

### 系统密码管理

每次新进入登录流程，页面 RESUMED 后自动请求一次密码选择器，关闭自动选中；取消或无凭据回到手动表单。登录输入框保留 Autofill 语义，用户可通过系统键盘或长按输入框提供的自动填充入口再次选择密码。返回、旋转和重组不重新自动请求。获取凭据期间表单保持正常可编辑，密码显隐可用；手动编辑、提交或进入注册／找回密码会作废待处理获取请求，并消费尚未发起的自动请求，迟到结果不能覆盖输入或触发认证。单纯聚焦不取消请求。指定账号重新登录时按邮箱筛选，选中密码仍执行现有服务端认证及邮箱／TOTP 验证。

手动输入的密码仅在完整认证和本机会话保存完成后提示保存；重置密码在服务端确认和本地旧会话清理完成后提示更新。直接选择且未修改的系统密码不重复保存。取消保存静默继续，保存失败提供非阻断提示，不撤销已完成的认证。密码仅在流程内存短暂保留，由用户确认后交给系统密码管理器；不写入应用账号库。游客、登出或移除当前账号只清理提供者的登录会话状态，不删除已保存密码。

保留 Compose Autofill 语义，取消旧 Autofill 会话以避免提前保存和重复弹窗。非生产 API 地址和隔离测试包禁用真实提供者；没有可用提供者仍可手动登录。Passkey、网页／App 密码共享关联不在本轮范围。替身验证与真实系统兼容性边界见[认证验证记录](auth-testing.md#认证体验与系统密码专项)。

## 关于与开源组件

“我 → 设置 → 关于 → 开源组件”使用 AboutLibraries 自带的 Material 3 列表和组件详情 Sheet，继承应用主题，支持离线阅读及返回栈、列表位置恢复。此页保留第三方列表样式，外层导航与顶栏沿用项目组件。

许可证数据按 Debug / Release 构建自动生成，并补充 Material Symbols 与 AOSP 转场移植声明。生成、维护与检查方法统一见[开源声明说明](../third_party/aboutlibraries/README.md)。

## 启动屏

启动屏始终跟随系统浅深色模式：浅色为品牌粉色背景和白色图标，深色为深灰背景和品牌粉色图标，不随应用内外观设置、动态颜色或自定义主题色变化。应用页面仍使用保存的外观设置。启动图标使用独立资源，桌面与关于页图标保持原样。

全新启动时，页面准备好后播放图标先收缩、再展开揭示页面的遮罩退出动画，页面自身不缩放。后台返回、旋转、页面恢复和应用内主题切换均不重播；关闭系统动画时直接显示页面。

离开前台、销毁或窗口尺寸变化时清理过渡。过渡期间屏蔽底层页面触摸与无障碍焦点，不拦截系统返回。配色、时序与清理机制见[启动动画](implementation.md#启动动画)。
