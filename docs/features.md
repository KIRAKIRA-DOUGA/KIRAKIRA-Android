## 尚未接入与已知限制

| 项目 | 现状 |
| --- | --- |
| 底栏的“关注”标签 | 占位页，显示“暂未开放” |
| 收藏 | 入口和页面都在，但没有数据和操作；视频页的收藏数显示 `—` |
| 视频的稍后再看、下载、举报，评论的回复 | 入口提示暂不可用，不改变任何状态或计数 |
| 播放 | 没有后台音频、离线下载和自动连播 |
| 首页 | 服务端最多返回 100 条，没有分页 |
| 搜索、标签页 | 接口没有分页，排序只作用于本次返回的结果 |
| 观看历史 | 没有分页，不能删除或清空；只同步首 P 的进度 |
| 弹幕 | 各分 P 共用一个弹幕池；读取不做个性化过滤 |
| 屏蔽规则 | 过滤完全由后端执行，规则保存成功不代表每个内容接口都已支持 |
| 隐私设置 | 保存成功不代表各读取接口已按它限制，详见[隐私设置](#隐私设置) |
| 登出 | 只清除本机会话，不撤销服务器上的 token |
| 密码管理 | 不支持 Passkey 和网页／App 的密码共享关联 |
| TOTP 绑定 | 后端不能取消或读取未完成的绑定，遗留记录可能影响之后的绑定 |
| 系统状态栏回顶 | 尚未在厂商设备上实机验收 |
| 资料页的背景图 | 显示本地占位图，不展示也不能编辑远程封面 |

## 数据保存在哪里

| 数据 | 保存位置 | 系统备份 |
| --- | --- | --- |
| 外观、预测性返回、背景景深、播放设置、弹幕显示设置 | 本机，所有账号共用 | 参与 |
| 应用语言 | Android 13+ 由系统保存；更低版本保存在本机 | 参与（低版本） |
| 账号列表与登录凭据 | 本机的应用私有目录，不额外加密 | 不参与 |
| 搜索历史 | 本机，按后端和账号分开，游客另存一份，各 30 条 | 不参与 |
| 最近使用的颜文字 | 本机，所有账号共用，24 项 | 不参与 |
| 观看历史与首 P 的播放进度 | 账号（云端） | — |
| 个人资料、隐私设置、屏蔽规则、邀请码 | 账号（云端） | — |
| 搜索条件与结果、评论和弹幕草稿、弹幕发送样式、倍速 | 只在内存，离开或进程重建后丢失 | — |
| 密码、验证码、TOTP 密钥、备用码与恢复码 | 只在当前流程的内存 | — |

## 主界面与导航

### 底栏与侧栏

窄窗口使用四项底栏：**首页、搜索、关注、我**。平板或展开的折叠屏有足够的连续空间时，改为起始侧的侧栏：上方是首页、搜索、历史、收藏、关注，下方是头像和设置。

- 底栏支持点击和按住拖动选择；可以跨标签直接切换，连续点击转向最新目标。
- 侧栏的头像在游客状态下打开登录，登录后打开自己的主页。
- 主界面、历史、收藏、自己的主页和设置目录共用同一个侧栏，在它们之间切换时侧栏保持原位；这些页面显示侧栏时隐藏左上角的返回按钮。
- 在侧栏的一级子页之间切换后，返回一次回到原来的主界面标签。
- 调整分屏或折叠时，保留当前标签、搜索条件和浏览位置。

### 回顶

- **重复点击当前标签**平滑回到当前内容的顶部；切到其他标签则保留其滚动位置。视频页、用户主页、邀请码、播放器设置和颜文字分类的页内标签使用同一规则。
- 用户主页只让当前的作品或收藏列表回顶，资料区的展开位置不变。评论的回顶见[评论与弹幕](#评论与弹幕)。
- 回顶保留筛选、输入和播放状态；手动拖动会中断回顶。
- **点击系统状态栏回顶**：在支持该手势的 HyperOS，以及发送对应状态栏广播的 ColorOS／realme UI、华为 EMUI 和兼容 Android 的鸿蒙系统上，点击状态栏可以回到当前页面正文的顶部。只响应当前页面的当前页签；菜单、对话框、搜索弹层、底部面板打开期间，以及转场、全屏、图片查看、画中画和后台期间不响应。系统实际采用单击还是双击、是否开放这项能力，由设备系统决定。这项能力没有设置项，也不申请权限；**尚未在上述厂商设备上实机验收**。

### 状态恢复与返回

- 选中的标签、首页与“我”的滚动位置可以恢复。从设置或视频页返回时回到原来的标签和位置。
- 在主界面按系统返回会退出应用，不会先跳回首页。
- 预测性返回是可选的，见[外观](#外观)。

### 折叠屏与宽窗口

- 平展且无遮挡的屏幕使用整个窗口；书本式半开且中缝无遮挡时，普通页面可以使用折痕两侧；有遮挡的铰链或横向半开时，页面收进可用的分区。
- 首页与搜索结果的网格随可用宽度增加到三列或四列；折痕两侧各放得下卡片时，视频流在折痕两侧分列。
- 用户主页在宽窗口（扣除侧栏后超过 720dp）或书本式折叠两侧都放得下时改为铺满窗口的双栏：起始侧是可独立滚动的资料栏，另一侧是“视频／收藏”标签与 2–6 列视频网格；书本式折叠时以折痕为分界。
- 设置在空间充足时显示“目录加详情”双栏，见[设置](#设置)。

## 首页

首页读取 Rosales 的 `/video/home`，支持下拉刷新、空结果和失败重试。封面、作者名、播放量和时长都来自服务器，缺失的字段显示中性占位，不生成虚构的统计。点击卡片进入视频页。

使用底栏时可以从首页顶栏的头像进入“我”；有侧栏时由侧栏的头像承担。

## 视频搜索

搜索页提供**关键词**和**标签**两种模式，游客也可以搜索。

### 关键词与标签

- 关键词通过键盘的搜索键提交，会去除首尾空白。
- 标签模式下，点击搜索框的空白处或加号打开全屏的标签选择器：输入名称查询已有标签（500 毫秒防抖），可以多选；确认后查询**同时包含全部所选标签**的视频，关闭则放弃本次选择。不能创建或编辑标签。
- 移除搜索框里已提交的标签会立即重新搜索；移除最后一个标签回到搜索历史。
- 输入框末端的叉号一次性清空当前条件、取消请求并清除结果，回到搜索主页。
- 切换模式时旧请求被取消、结果清空，但关键词和所选标签都保留；切回标签模式且已有标签时立即搜索，关键词模式等待提交。
- 标签按当前语言显示名称，候选同时展示不同的原名。

### 结果

- 结果区顶部显示实际返回的数量，并提供排序和“网格／列表”切换。
- 排序有默认顺序、上传时间、播放量和时长四项。点击未选中的项按降序排列，再次点击切换升降序；缺失值始终排在最后。**排序只作用于本次已返回的视频**，接口没有分页，不提供全站排序。
- 同一条件下拉刷新时保留已有内容、空状态和滚动位置；失败保留原内容并提供重试。
- 空输入不发请求。

### 搜索历史

未提交搜索时显示“最近搜索”，关键词与整组标签按最近使用的顺序混排。

- 点击一条记录恢复条件并立即搜索。支持单条删除，以及确认后清空当前账号的全部历史。
- 每个后端和账号各保存最多 30 条，游客另存一份。关键词精确去重，标签组合按 ID 集合去重，重复使用会置顶。
- 有效的提交会被记录，即使搜索失败或没有结果；候选查询、模式切换、刷新、排序和布局切换不产生记录。
- 记录只保存在本机，重启后保留，不上传，也不参与系统备份。本地记录损坏时清除该部分并回到空历史。

### 状态保留

输入、所选标签、结果、排序、布局和滚动位置只在内存里：切换标签页、打开视频后返回和旋转时保留；进程重建后回到未提交状态。切换账号或登出会清空它们，并加载对应账号的搜索历史。

点击空白处可以收起键盘，不会退出搜索或关闭选择器。

## 历史记录

“我 → 历史记录”展示当前账号的云端观看记录，游客看到登录入口。

- 记录按设备本地时区的日期分组，日期和记录都是倒序。每条显示封面、标题、作者、观看时间和有效的播放进度，点击进入视频页。
- **搜索**在本地实时匹配标题和作者（忽略大小写和首尾空白），不发请求；结果保留日期分组，可以刷新和打开视频。从搜索结果打开视频再返回，搜索内容和位置都还在。系统返回依次收起键盘、收起搜索、离开历史页。
- 下拉刷新保留已有列表或空状态；从视频页返回时会自动刷新。
- 历史只缓存在内存，账号切换、登出时清空。**不提供删除或清空操作。**

### 进度同步与续播

- 已登录账号的**首 P** 播放进度同步到云端，与 Apple 客户端共用整数秒的锚点。其他分 P 仍会产生浏览记录，但不写入也不恢复云端进度。
- 播放期间每 5 秒检查一次，位置变化达到 15 秒时提交；暂停、切换视频或分 P、释放播放器和进入后台时，变化达到 1 秒就尽力提交。
- 同步失败不打断播放，也不自动重试；没有离线队列，进程被强杀时最后一次提交不保证成功。
- **续播**：新的播放会话会自动回到上次的位置，条件是该位置至少 3 秒，并且距离结尾超过 10 秒；临近结尾则从头开始。续播时播放器左下角短暂提示已回到上次的位置。
- 续播的准备最多等待 1.5 秒，失败或超时就从头开始；手动点击播放不受这个等待限制。手动播放、切换分 P 或跳转之后，不再应用迟到的云端位置。
- 历史查询失败不影响视频的加载与播放。

## 视频页

### 布局

窄窗口是上方播放器、下方详情。足够宽的窗口和空间充足的纵向折叠分区采用双栏：横屏双栏时，播放器下方常驻可滚动的简介，另一侧只有“评论”“弹幕”两个标签页。横向半开的折叠屏在上屏播放，下屏显示播放控制和详情。切换布局不会重新开始视频，也不会清空评论和弹幕的草稿。

### 播放

- 视频默认显示封面，点击播放后才开始加载。开启“设置 → 播放 → 自动播放”后，新进入的视频页在前台取得可播放内容时自动开始一次；它不因刷新、旋转、从后台返回或进程恢复而再次触发。
- 支持 HTTPS 的 DASH、HLS 和渐进式媒体，支持播放／暂停、进度拖动、分 P 选择、全屏和失败重试。
- 多个分 P 时，“简介”页提供切换入口；手动切换后从头播放，暂停时切换仍保持暂停。刷新详情后分 P 的顺序变化不影响当前分 P 和进度；当前分 P 被删除时回到首 P 并暂停。
- 视频详情在首次进入页面时加载；从其他页面返回或从小窗恢复时不自动刷新，可以下拉刷新。
- 页面恢复时保留分 P 和位置，但不自动播放。
- 视频详情失去访问权限时停止播放，撤下封面、评论和弹幕，并关闭应用内小窗；在评论或弹幕页重试会先重新核对视频详情。

### 控制栏与手势

- 无操作 3 秒后控制栏和返回按钮一起隐藏，轻触画面切换显隐。缓冲、出错、拖动进度、设置面板打开和 TalkBack 触摸探索期间保持显示。
- 点击时间标签在“已播放时长”和“剩余时长”之间切换。
- **横向拖动**预览目标时间，松手才跳转，取消则不跳转；滑满画面最多对应 90 秒。
- **双击**左侧三分之一后退 5 秒，右侧三分之一前进 5 秒，连续点击累计；中间区域双击切换播放与暂停。
- **右半区上下滑动**调节系统媒体音量。不调节屏幕亮度。
- 从左右边缘开始的拖动不触发播放器手势。首次加载、失败和设置面板打开时手势不可用；时长未知或媒体不可跳转时不能拖动进度。小窗和系统画中画没有这些手势。

### 画质与倍速

- **画质**选项来自媒体实际提供的视频轨道，有“自动”和按清晰度排列的手动选项，并显示码率。自动／手动模式和首选清晰度全局保存；某个视频没有首选的清晰度时临时使用自动，不改动保存的偏好。
- **倍速**有 0.25× 到 4× 的快捷项和滑杆，也可以在面板的码表上拖动。默认吸附到预设值，开启“无级调速”后可以按两位小数调整；“保持音调”默认开启。
- 倍速和这两个开关在当前视频内保留（包括切换分 P 和页面恢复）；进入新的视频时恢复为 1×、关闭无级调速、开启保持音调。
- 播放器右上角的齿轮打开设置面板，可以调整小窗、自动播放和弹幕显示选项，与应用设置页是同一份设置。

### 全屏

窄窗口进入全屏时旋转为横屏，支持两个横屏方向；宽窗口、分屏和大屏环境在当前窗口内直接全屏，存在分隔铰链时全屏限于播放区域。退出后恢复之前的方向。全屏期间详情不可操作，但所选标签页、列表位置和输入草稿都保留。返回键先关闭已打开的面板，再退出全屏。

### 应用内小窗与系统画中画

“设置 → 播放”提供两个开关，均默认开启，全局保存：

| 开关 | 作用 |
| --- | --- |
| 应用内小窗播放 | 播放中（或缓冲待播放时）离开视频页，视频缩成应用内的小窗继续播放 |
| 应用外小窗播放 | 正在播放时离开应用，自动进入系统画中画 |

- 小窗可以拖动并吸附到左右边缘，避让系统栏、键盘和底部导航。点击左上角回到视频页，点击右上角关闭并停止播放。
- 回到视频页时保留分 P、进度、画质、倍速和暂停状态。小窗不显示弹幕、进度条和设置面板。
- 暂停、结束或出错状态下离开视频页不会创建小窗；已创建的小窗暂停后仍保留。
- 小窗播放时点击另一个视频，新视频打开，旧小窗暂停并消失。
- 系统画中画只显示视频，由系统提供播放／暂停控制。不支持、未允许或没有进入画中画时，进入后台会释放播放器。关闭画中画即停止播放。
- 账号切换、登出或播放失败会清理播放会话。进程重建后不自动恢复播放或小窗。

返回时，正在播放且允许应用内小窗的视频缩到小窗，其余情况收回来源的卡片。

### 简介

简介展示作者、关注关系、标题、播放量、日期、分区、描述、标签和操作条。

- 描述默认最多三行，超出时可以展开和收起；同一视频刷新、切换标签页和旋转时保留展开状态。
- 分区名称随应用语言显示，未知的分区保留接口原值。
- 标签按服务端顺序显示。点击标签进入标签页，查看原名和关联的视频；游客可以浏览。
- **操作条**依次是点赞、点踩、收藏、分享、更多。赞踩显示真实数量，数量未知时显示 `—`。“更多”里有稍后再看、查看封面、下载和举报；其中只有分享和查看封面可用。
- 游客点击赞踩或关注会进入登录；登录后需要用户再点一次，不会自动补发。
- 赞踩和关注的状态在服务器确认后才更新，操作期间不能重复提交。关注请求结束后（包括超时这类结果不确定的失败）会重新读取详情核对状态。
- 自己的视频不显示关注按钮。

## 评论与弹幕

### 评论

- 评论按服务端的楼层升序，每页 20 条，向上和向下都能连续加载；接近列表边缘时自动补齐相邻页，向前插入时保持当前的阅读位置。
- 右上角的工具栏可以翻到上一页、下一页或输入页码跳转。跳到尚未加载的页时保留当前位置，目标页加载成功后才跳转；失败则保留原内容和位置。
- 只能发布一级的纯文本评论（非空，少于 20,000 字符）。发布成功后读取并定位到末页。评论里的 HTML 不会被渲染。
- 只有回到第 1 页的最顶部才能下拉刷新；中间页的顶部只用于加载上一页。
- 重复点击评论标签或使用状态栏回顶，会回到第 1 页的评论数量标题。
- 不提供后端没有实现的全局评分排序和楼层定位。

### 弹幕

- 视频页就绪后自动读取弹幕，不需要打开弹幕标签页。读取失败不影响视频，可以在弹幕标签页手动重试。
- 画面上的弹幕支持四种模式（从右向左、顶部、底部、从左向右）、原始颜色、三档字号和彩虹描边。暂停和缓冲时冻结；跳转或全屏之后按当前进度恢复；系统画中画里不显示。轨道放不下时跳过那一条，不延迟堆积。
- 默认速度下，滚动弹幕约在 6–8 秒内穿过画面；同一画面里长短弹幕的显示时长相同。固定弹幕显示 4 秒。两者都随视频倍速变化。算法见[弹幕显示实现](implementation/media.md#弹幕显示与设置)。
- **发送**：输入上限 2,000 字符，发送时记录当前分 P 的播放秒数。可以选择颜色（九种预设或自定义）、字号、模式和“创作者专属渐变”。发送样式在当前视频内保留，退出视频、进程重建或切换账号后恢复默认，不持久保存。
- 发送成功后刷新弹幕池，不额外插入本地副本。
- Rosales 的弹幕不区分分 P：各分 P 共用一个弹幕池，按当前分 P 的播放时间显示。

**“设置 → 弹幕”**提供显示开关、不透明度（10%–100%）、字号缩放（50%–200%）、显示区域（25%／50%／75%／100%）、滚动速度（0.5×–2×）和四种模式各自的开关。默认全部显示、100% 不透明度和字号、全区域、1× 速度。这些设置即时生效，本机所有账号共用，重启后保留，参与系统备份；它们不影响发送样式。没有密度设置。

### 输入区

- 未登录时，评论和弹幕标签页底部的发送栏是一个“登录后即可互动”按钮；点击后暂停播放并进入登录。登录后由用户主动发送，不自动发送。
- 已登录时底部是常驻的输入区，随键盘上移。输入框最多自动增高到五行。
- **颜文字**：点击入口收起键盘并展开面板，有开心、问候、卖萌、忧伤、无语五类共 268 项，以及“最近使用”。点击条目在光标处插入（或替换选中的文字），可以连续选择，不自动发送；超出字数上限时整项拒绝。最近使用保存最新的 24 项，评论、弹幕和本机所有账号共用，重启后保留。
- 点击输入区和面板以外的地方会收起键盘和面板，草稿保留。切换标签页、打开弹幕样式、进入全屏或画中画也会关闭面板。
- 发送成功清空正文，失败保留草稿。账号切换会取消旧请求并清除草稿。

### 发布结果不确定

评论或弹幕发布遇到超时、网络中断这类结果不确定的失败时，草稿保留，并提供“查看最新内容”和“再次发送”。再次发送会提示可能重复；取消之后再提交相同的内容仍需确认。客户端不自动重发。

## 用户主页

### 资料与作品

- 作者入口按 UID 加载用户资料、关注统计和作品。“我”的主页使用同一布局，并用本机的账号资料作为加载期间的回退。
- 资料区随滚动移出，“作品／收藏”标签栏吸顶，吸顶后顶栏显示昵称。收藏标签页尚未开放。
- 首次读取关注数和粉丝数时显示占位；数字出现后可以点击进入对应的列表。
- 自己的主页显示“编辑资料”按钮，进入[资料编辑](#资料编辑)。
- 关注按钮的状态在服务器确认后更新，操作期间禁用。
- 头像和顶部横幅都可以点击，进入[图片查看](#图片查看)。

### 关注与粉丝列表

- 列表沿用服务器“最近关注优先”的顺序，每页 50 条，接近末尾时自动加载下一页；返回时保留已加载的内容和滚动位置。点击一行进入该用户的主页。
- 列表里不提供关注或取消关注的操作。
- 刷新失败保留原内容；分页失败在末尾提供手动重试，不自动循环请求。只有会话失效或服务器明确确认不可访问时才清除内容。
- 切换账号或变为游客时清空列表。列表不保存到本机。

### 屏蔽与隐藏

他人主页右上角的“更多”菜单可以隐藏、屏蔽，或取消这两种状态；点击后直接提交。

- 游客需要先登录，登录后不会自动执行。
- 菜单显示当前已确认的状态。提交和状态核对期间不能重复操作；失败后重新读取状态。
- 屏蔽之后，用户页不再展示作品和关注操作，但保留返回、刷新和取消屏蔽的入口。
- 隐藏不阻止访问该用户页；内容的过滤由后端执行。

### 分享

用户页的菜单和视频页的分享按钮都打开 Android 系统的分享面板，游客也可以使用。分享的正文是昵称（或视频标题）加公开链接，名称不可用时只分享链接。用户地址为 `https://kirakira.moe/user/{uid}`，视频地址为 `https://kirakira.moe/video/kv{id}`；不附带播放进度或账号信息。

## 图片查看

头像、资料页横幅和视频封面可以打开全屏查看器。

- 支持缩放、保存和复制；未放大时可以单指下拉退出，拖动距离不足或加入第二根手指时恢复。下拉退出不受“预测性返回”开关的影响。
- 头像和横幅打开时从原位置展开，关闭时收回原位置；视频封面没有来源位置，居中淡入淡出。
- 查看和导出使用原图地址，网络请求不携带会话。原图加载失败时降级为受限尺寸的预览；完全失败时保留关闭和重试。加载状态不会让查看器自己关闭。
- **保存**写入公共的 `Pictures/KIRAKIRA`；**复制**把原图交给系统剪贴板。导出的始终是原始文件，不是预览图。
- 已开始的保存或复制在退出查看器后继续进行，完成或失败都会有提示。任务只在应用本次运行期间保留，Activity 结束或进程终止后不保证完成。
- 查看器打开期间暂时隐藏应用内的视频小窗，播放会话保留；从视频页打开时，视频页留在查看器下方。

## 账户与认证

### 切换账户

“设置 → 切换账户”把游客固定在最上面，其后是本机登录过的账号。

- 点击其他账号会先向服务器校验并更新资料，校验和本机保存都成功后才切换。失败时不替换当前账号，并标明是哪个账号、提供重试或重新登录。
- 切换到游客可以离线完成，其他账号的会话保留。
- 网络故障或超时时，账号和登录信息仍然保留，可以重试或继续使用。明确失效的 token 会被清除，但账号条目保留，方便重新登录。
- 账号可以通过左滑、编辑模式或无障碍入口移除，都需要确认；游客不能移除。
- 移除当前账号或在设置里登出，会清除本机的这个会话并回到游客，其他账号不变。**这不会撤销服务器上的 token。**

### 账号的存储

- 账号资料与登录凭据以 JSON 保存在应用的私有目录，不额外加密，依靠应用沙盒和系统的存储保护；不参与系统备份。
- 存储故障会区分空间不足、数据格式异常和其他读写错误。故障可以重试；必要时在明确确认后清除本机的账号数据，服务器上的账号不受影响。
- **从旧版本升级**：只有在新账号文件不存在时才尝试恢复旧的加密登录信息。恢复成功则保留账号和当前登录的选择；旧文件或密钥不可用时进入游客状态，并提示一次“原有登录信息无法恢复，请重新登录”。旧账号属于另一个后端环境时会完整迁移并保留，只是当前环境显示为游客。

### 登录、注册与找回密码

- **登录**先检查二步验证：未开启时直接登录；开启邮箱验证的账号进入六位验证码步骤；开启 TOTP 的账号接受验证器验证码、备用码和恢复码。使用恢复码会移除验证器，界面会提前说明。
- **注册**分四步：资料（用户名和昵称必填）、邮箱与密码、邀请码、邮箱验证。成功后获得会话并回到进入认证之前的页面。
- **找回密码**：没有 TOTP 的账号通过邮箱验证码设置新密码，完成后回到登录；开启了 TOTP 的账号只提供说明和联系管理员的入口，不伪造找回接口。
- **验证码**按邮箱有 60 秒冷却，并受服务端的冷却和每日次数上限约束。关闭再打开页面，当前进程内冷却仍然有效。
- 六位验证码支持连续输入、整段粘贴和退格，不自动提交。
- 返回逐级回到上一步，保留验证码以外的草稿；登录首页通过系统返回退出认证。返回时取消当前请求。
- 邮箱可以随页面恢复；密码和验证码不落盘，进程重建后回到登录页。
- 关闭认证页会取消其中的请求，请求失败不会被显示成已登录。

结果不确定时的处理：

| 情况 | 行为 |
| --- | --- |
| 服务端已认证，但本机保存失败 | 留在当前页，重试只保存会话，不会重复注册或再次消耗验证码 |
| 注册请求结果不确定 | 回到预填邮箱的登录页，提示账号可能已创建；不自动重发 |
| 重置密码结果不确定 | 清空凭据，提供重新登录；返回登录前清理对应的本机会话，不保存未确认的新密码 |

实现与安全边界见[认证与会话](implementation/auth.md#api-与会话)。

### 系统密码管理器

- 登录页直接显示表单，不主动弹出密码选择器。已保存的密码通过输入框的系统自动填充入口选择，填充后由用户提交。
- 手动输入的密码只在完整认证并且本机会话保存完成之后，才提示保存到系统密码管理器；重置密码则在服务端确认之后提示更新。来自密码管理器且未修改的密码不重复保存。
- 取消保存不影响登录；保存失败只给出提示，不撤销已完成的认证。
- 应用自己不保存密码。登出或移除账号只清理密码提供者的登录状态，不删除已保存的密码。
- 非生产的 API 地址构建不使用真实的密码提供者；没有可用的提供者时仍可以手动登录。

真实密码管理器的兼容性尚未验证，见[认证离线测试](auth-testing.md#尚未验证的部分)。

## 设置

设置分为“我”“常规”和账户操作三组。资料、隐私、安全、屏蔽和隐藏、邀请码与登出只在已登录时显示；游客可以使用外观、播放、弹幕、语言、关于和切换账户。

- **双栏**：空间充足时，目录和搜索常驻一侧，另一侧显示所选分类。返回先退出子页，再清除选择，最后退出设置。登录、头像裁剪和账号安全的操作占用完整页面。窄窗口逐页显示，调整窗口时保留当前页和滚动位置。
- **搜索**：按当前界面语言的设置名称和分类路径实时匹配，忽略英文大小写，多个词要全部匹配。点击结果进入所在页面并定位到条目。游客只能搜到通用设置和切换账户。搜索不保存历史。
- 恢复旧的返回栈或会话失效之后，需要登录的设置页显示登录入口，登录后回到原页面。

## 资料编辑

“设置 → 资料”和自己主页上的“编辑资料”是同一个页面，可以编辑头像、用户名、昵称、简介、生日、性别和个人标签。

- 用户名与昵称必填。缺少昵称的旧账号可以正常登录和浏览，下次保存资料时必须补填。
- 头像通过系统的图片选择器选择，在应用内裁剪（移动、缩放、旋转）。确认裁剪只改变草稿，点击保存才上传。不申请广泛的媒体访问权限。
- 生日可以不设置、清除或选择非未来的日期。性别提供未设置、男、女、其他；已有的自定义值在不修改性别时原样保留。
- 不能编辑背景图，也不能重置资料；保存时保留服务端原有的背景字段。
- **保存**在顶栏右侧，没有修改或图片还在准备时不可用。成功后留在页面，并更新“我”、本机账号列表和自己的主页；失败保留草稿。
- 服务端已保存、但刷新或本机存储失败时，按钮变为“重试同步”，只执行剩下的步骤。
- 有未保存的修改时，返回需要确认。旋转保留草稿；进程重建后重新读取服务端，不恢复未保存的草稿。账号切换或失效会清除草稿。
- 选图和裁剪产生的文件只存在应用缓存里，替换、取消和退出时清理；异常终止留下的缓存在下次进入编辑页时清理。

## 账号安全

安全入口只对已登录的账号显示。首页显示二步验证状态，以及修改邮箱和修改密码的入口。

- **修改邮箱**分两步：先填写新邮箱，再输入当前密码、当前邮箱的验证码（开启 TOTP 时改用验证器的验证码）和新邮箱的验证码。两封邮件各自发送。
- **修改密码**分两步：先填写新密码，再输入当前密码和验证码。新密码不能与旧密码相同。成功后只移除当前这个本机会话并打开登录页；其他本机账号保留，也不撤销服务端的 token。
- **二步验证**：邮箱验证和 TOTP 验证器互斥。
  - 邮箱验证可以直接确认启用；关闭时需要密码和邮箱验证码。
  - TOTP 绑定分“绑定验证器”和“保存代码”两步。绑定时提供二维码、打开验证器和复制密钥；确认后**一次性**展示五个备用码和一个恢复码，之后无法再次读取。
  - 解绑 TOTP 需要密码，加上验证器的验证码或一个备用码；不能用恢复码解绑。
  - 同一次进入安全页期间，返回后再进入可以继续已有的绑定，不会重复创建。
- 核验页返回填写页时保留新邮箱或新密码，清空当前密码和验证码；有输入的填写页和代码展示页离开前需要确认。发送验证码、提交和同步期间不能返回，也不能重复操作。
- 密码、验证码、TOTP 密钥、备用码和恢复码只存在当前页面的内存里；进程重建后回到安全首页重新读取。密钥和代码只能通过专用按钮复制，离开对应步骤时会清理本应用放进剪贴板的内容；不提供文件导出。

结果不确定时的处理：

| 操作 | 行为 |
| --- | --- |
| 修改邮箱 | 清空凭据并暂停编辑。只有重新读到目标邮箱才算完成；读到旧邮箱时继续保持核对。可以确认离开，但离开不会撤销可能已经生效的修改 |
| 修改密码 | 无法查询是否已修改。提示新密码可能已经生效，并提供重新登录；不自动重发 |
| 二步验证的写操作 | 显示“状态待确认”，只能查询状态，不能发起新的写操作。查询成功后按实际状态恢复 |
| 创建 TOTP 绑定的结果丢失 | 无法重新读取密钥，当前流程不再创建，提示联系管理员 |
| 服务端已保存、本机同步失败 | 只重试本机同步，不再次修改 |

Rosales 目前没有取消或读取未完成 TOTP 绑定的接口。离开安全页或进程重建之后，客户端不再持有绑定材料，服务端遗留的未确认记录可能干扰之后的绑定，需要后端处理。

## 隐私设置

“设置 → 隐私”可以设置生日、年龄、关注、粉丝和收藏的可见性，每项可选“公开”“仅关注者”“隐藏”。顶部的“全部设为”可以一次设置五项。

- **每次选择后立即提交**，没有“应用”按钮；选择当前值不会重复请求。
- 顶栏的“重置”经确认后把五项都设回“公开”；已经是默认值时不可用。
- 请求期间不能重复操作，也不能返回。
- 保存被明确拒绝时，界面恢复最近确认的值并提示错误。
- 结果不确定（超时、网络故障、服务异常，或写入后的核对读取失败）时进入待确认状态，暂不显示可编辑的旧值；用户通过“重试同步”只读取服务端的当前设置，读取成功后恢复编辑。不自动重发。
- 旋转保留当前状态；进程重建后重新读取。设备上不保存隐私设置的副本。

**已知的后端问题**：“设置已保存”只表示后端保存成功，不代表所有内容接口都已按它限制。当前 Rosales 的关注和粉丝权限检查使用 `privacy.follow`、`privacy.fans`，而设置接口保存的是 `privary.follow`、`privary.fans`；两者名称不一致，结果是默认公开。生日、年龄和收藏在各读取接口上的限制，也不在客户端能保证的范围内。

## 屏蔽和隐藏、邀请码

### 屏蔽和隐藏

“设置 → 屏蔽和隐藏”管理五类规则：屏蔽用户、隐藏用户、标签、关键词和正则表达式。总览显示每类的数量；管理页每页 20 条，支持下拉刷新、加载更多、添加和解除。

- **用户**通过 UID 查询后确认添加。已经被自己屏蔽的用户仍可以按确认的 UID 添加隐藏规则。
- **标签**使用与视频搜索相同的选择器，选中一个已有的标签后确认添加。
- **关键词与正则**限制为 1–30 个字符；正则的语法和安全性由服务端校验。
- 缺少 UID 的用户规则无法调用后端“按 UID 解除”的接口，所以不提供解除操作。

### 邀请码

“设置 → 邀请码”显示未使用、已使用和总数，支持生成、按状态筛选和复制。

- 列表里未使用的排在前面，同组按生成时间倒序。
- 生成成功后新码立即显示，即使随后的列表刷新失败也不会丢。
- 生成的冷却由服务端决定，接口没有提供剩余时间，所以不显示倒计时。
- 生成结果不确定时，会提示并重新读取列表；之后再次生成前要确认可能重复的风险。
- 不提供分享、删除或兑换。

两处的数据都保存在当前账号的服务端。切换账号或退出会清除列表、输入和弹窗。内容的过滤由后端执行，应用不维护本地的过滤引擎。

## 外观

### 明暗模式与个性色

“设置 → 外观”分别选择明暗模式（跟随系统、浅色、深色，默认跟随系统）和个性色。

- 个性色有七种预设：心爱粉、智乃蓝、理世紫、千夜绿、纱路黄、麻耶青、小惠红，默认是心爱粉 `#F06E8E`。图片来源见 [Cerasus 个性色资源](../third_party/cerasus-palettes/README.md)。
- **系统强调色**只在 Android 12+ 显示，默认不选；选中后颜色随系统的配色设置更新。
- **自定义颜色**提供色盘、亮度，以及 HEX、RGB、OKLCH 三种输入。输入未完成或无效时不能应用；超出 sRGB 色域的 OKLCH 输入会被调整并提示。草稿只在确认后保存，取消不改变主题。
- 预设、系统强调色和自定义三者互斥选中。选择预设或系统强调色不会覆盖已保存的自定义颜色；自定义的色值恰好等于某个预设时，仍然算作自定义。
- 主题与预设的选择立即生效并保存。
- 为了保留所选的原色，极浅或极深的颜色可能对比不足，不保证所有文字都达到 4.5:1。

### 动画

“设置 → 外观 → 动画”有两个开关，都立即生效，本机所有账号共用：

| 开关 | 默认 | 作用 |
| --- | --- | --- |
| 预测性返回 | 关 | 开启后，边缘返回手势会显示跟手的页面预览，可以中途取消；关闭时手势完成后直接播放普通的返回转场。图片查看器同样遵循这个开关 |
| 背景景深 | 开 | 视频页与卡片、小窗之间缩放时，后方的页面会模糊、压暗并略微缩小；关闭后只压暗 |

背景景深的完整效果需要 Android 13+；Android 12 只有模糊和压暗，Android 8.1–11 没有背景效果。

### 毛玻璃与阴影

顶部栏、主界面的底部导航栏和视频页的标签栏固定使用毛玻璃背景；Android 12+ 是实时模糊，Android 8.1–11 是半透明背景。阴影也固定开启。两者都没有开关。

## 语言

“设置 → 语言”默认“跟随系统”，也可以手动指定 English、简体中文、繁體中文或日本語。

- 选择后界面原地切换，不重建页面，当前位置、返回栈和输入内容都保留。
- 日期（历史日期、生日、内容发布时间等）的格式随应用语言更新。
- Android 13+ 与系统设置里的“应用语言”互通；更低的版本把手动选择保存在本机。

## 关于与开源组件

- 关于页的版本信息显示为 `versionName (versionCode)`。
- “开源组件”列出第三方组件及其许可，支持离线阅读。许可数据随构建自动生成，并补充了没有通过 Gradle 引入的第三方资源；维护方法见[开源声明说明](../third_party/aboutlibraries/README.md)。
- **组件库**：所有构建都可以长按关于页顶部的图形 Logo 进入。它按分组展示应用使用的共享组件及其各种状态，示例离线运行，供开发时对照。详情页的“重置”恢复本页的默认值。

## 启动屏

- 启动屏始终跟随**系统**的浅深色，不随应用内的外观设置变化。
- 全新启动时，页面准备好后播放一次图标展开、露出页面的动画。从后台返回、旋转、页面恢复和应用内切换主题都不重播；关闭系统动画时直接显示页面。
- 过渡期间底层页面不响应触摸，但系统返回仍然可用。

机制见[启动动画](implementation/navigation.md#启动动画)。

## 加载、失败与空状态

以下规则适用于所有内容页面。

- **读取失败保留已有内容**。已有内容时刷新失败，内容保留并显示错误和重试入口。限流、响应异常和一般的业务拒绝都不会清空内容；只有会话失效或服务器明确确认不可访问时才清除。
- **空状态也是一种已加载的状态**。刷新期间它保持显示，由下拉刷新的指示器反馈进度。
- **无效数据逐条略过**。列表里单条数据无效时略过那一条，整批都无效才显示空状态。视频标题缺失时留空，视频仍可浏览。
- **写请求不自动重发**。游客触发需要登录的操作时进入登录，登录后由用户再操作一次。
- **操作期间防止重复提交**，按钮显示进度。
- 图片加载失败和视频播放失败时，在原位置显示错误与重试，返回、关闭和全屏入口仍然可用。
- 收藏和关注的“未开放”占位不提供重试。
- 数字（赞踩、关注数、评论和弹幕总数、结果数量等）变化时逐位滚动；数值来自实际的操作结果和刷新，不做预先加减。
